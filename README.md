# Vehicle Advertisements Dashboard

Aplicação disponível em:

https://render-project-tz39.onrender.com

Este projeto é um aplicativo web desenvolvido com Streamlit para realizar uma análise exploratória de anúncios de veículos.

## Funcionalidades

- Exibe um histograma da quilometragem dos veículos.
- Exibe um gráfico de dispersão entre preço e quilometragem.
- Utiliza Pandas para manipulação dos dados.
- Utiliza Plotly Express para gerar gráficos interativos.
